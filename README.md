> The application interface is in French.

## Features

### Real-time click tracking
- Displays **left click** and **right click** CPS simultaneously in real time
- Toggle the Left/Right labels on or off

### Fully customizable display
- Adjustable **text size**, **window width**, and **window height** via sliders
- Custom **color** for left and right click counters separately

### Window options
- **Always on top** — stays visible over any game or application
- **Show/hide title bar**
- **Lock window position**
- **Game mode** — clicks pass through the window so it doesn't interfere with gameplay
- **Re-center window** button
- **Reset settings** button

---

## Usage

1. Download `CPS.exe` from the [Releases](https://github.com/xHatefulMan/CPS-Counter/releases) page
2. Run it — no installation needed
3. Click anywhere to start tracking your CPS
4. Open settings with the ⚙️ button to customize the display
